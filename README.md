# Laboratorio de movimiento 2D

Proyecto académico desarrollado en Unity 6000.0.82f1 con URP 2D.

## Ejecución

1. Abre esta carpeta desde Unity Hub.
2. Abre `Assets/_Project/Scenes/LaboratorioPA1.unity`.
3. Pulsa Play y haz clic dentro de la vista Game.

## Controles

- A/D o flechas: movimiento horizontal con `Input.GetAxisRaw`.
- Espacio: salto únicamente al detectar suelo.
- R: reiniciar la escena.

## Contenido

Incluye paredes y plataformas, una caja con `Rigidbody2D` dinámico y una moneda con `Collider2D` configurado como trigger. El código principal está en `Assets/_Project/Scripts`.
